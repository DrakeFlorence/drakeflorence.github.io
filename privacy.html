1. 关于本应用

本应用是应用所有者个人自用的 OAuth 客户端，仅供 rclone 命令行工具在其自有服务器上执行自动化备份时使用。本应用不面向公众提供服务、不开放注册，使用者仅应用所有者本人（1 人）。

2. 访问哪些数据

经账号所有者明确授权后，本应用通过 Google Drive API 访问以下范围：

  • https://www.googleapis.com/auth/drive —— 读取、创建、删除该 Google Drive 中的文件。

本应用不会访问 Gmail、通讯录、日历、相册或任何其他 Google 服务的数据。

3. 数据用途

仅用于唯一目的：将应用所有者自有服务器的网站与数据库备份文件上传至其本人的 Google Drive，并清理超出保留期的旧备份。不用于广告、用户画像、数据分析或任何其他用途。

4. 数据存储与保留

  • 备份文件存放于应用所有者本人的 Google Drive，受其账号的存储配额与安全设置约束。
  • OAuth 授权令牌仅存放于应用所有者本人的服务器（文件权限 600，仅系统管理员可读），不发送至任何第三方。
  • 本应用不自建服务器、不采集、不中转、不留存任何用户数据。

5. 数据共享

本应用不向任何第三方出售、出租、共享或披露任何数据。除完成上述备份所必需的 Google Drive API 调用外，不与任何外部系统通信。

6. 数据安全

授权令牌以受限权限存储，仅服务器管理员可读；与 Google 的全部通信经 HTTPS/TLS 加密；备份文件的访问控制由应用所有者本人 Google 账号的安全设置（含两步验证）保障。

7. 你的权利

  • 可随时在 myaccount.google.com/permissions 撤销本应用授权，撤销后本应用立即无法访问该 Drive。
  • 可随时在 Google Drive 中自行删除本应用创建的任何文件；删除对应文件夹即等同删除本应用创建的全部数据。

8. Google API 服务用户数据政策

本应用对自 Google API 获取之信息的使用，遵守 Google API Services User Data Policy，包括其中的有限使用（Limited Use）要求。

9. 政策变更

1. About this application

This application is a personal-use OAuth client. It is used solely by its owner to run the rclone command-line tool on a server they own, for automated backups. It is not offered to the public, does not allow registration, and has exactly one user — the application owner.

2. What data is accessed

With the account owner's explicit authorization, this application accesses the following Google Drive API scope:

  • https://www.googleapis.com/auth/drive — read, create, and delete files in that Google Drive.

This application does not access Gmail, Contacts, Calendar, Photos, or any other Google service.

3. How the data is used

For one purpose only: uploading website and database backup files from the application owner's own server to their own Google Drive, and removing backups that have exceeded their retention period. The data is not used for advertising, profiling, analytics, or any other purpose.

4. Storage and retention

  • Backup files are stored in the application owner's own Google Drive, subject to that account's storage quota and security settings.
  • The OAuth authorization token is stored only on the application owner's own server (file mode 600, readable by the system administrator only), and is never transmitted to any third party.
  • This application operates no servers of its own and does not collect, relay, or retain any user data.

5. Data sharing

This application does not sell, rent, share, or disclose any data to any third party. It communicates with no external system other than the Google Drive API calls required to perform the backups described above.

6. Data security

The authorization token is stored with restricted permissions, readable only by the server administrator. All communication with Google is encrypted over HTTPS/TLS. Access to backup files is governed by the application owner's own Google Account security settings, including two-step verification.

7. Your rights

  • You may revoke this application's access at any time at myaccount.google.com/permissions. Once revoked, the application immediately loses all access to the Drive.
  • You may delete any file created by this application directly in Google Drive. Deleting the corresponding folder deletes all data created by this application.

8. Google API Services User Data Policy

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

If this policy changes, the “Last updated” date at the top of this page will be revised.
